## About

- I created a REST API using NodeJS and ExpressJS. And to deploy this application using Infrastructure as a Service(IaaS) deployment model. The combination of Amazon EC3 and NodeJS. This application encrypts and decrypts the message using the RSA algorithm for security.

- I used the public key for the encryption and the private key for the decryption of message.

### Prerequisites

Git needs to be installed on your machine.
The first step is to clone the tutorial repo in your machine using the below command.

```
git clone https://github.com/ShvetK/Amazone_EC2-NodeJS-RSA.git
```

then change the directory using the below command

```
cd Amazone_EC2-NodeJS-RSA
```

After installing node_modules using

```
npm install
```

Start app using

```
npm start
```

You need the tools/libraries/software below to run this project on your machine.

- [VS Code](https://code.visualstudio.com/)
- [Node](https://nodejs.org/en/)
- [npm](https://www.npmjs.com/)
- [Express](https://reactjs.org/)
- [Axios](https://www.npmjs.com/package/axios)
- [Nodemon](https://nodemon.io/) (optional)
